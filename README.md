# stschool

Система приёмки ответов на занятии и домашних заданий. $mol + Giper Baza, без сервера.

## Экраны

- `#!` — список групп: учитель заводит группу, ученик видит группы, в которые вошёл.
- `#!join=<ленд>` — вход ученика по ссылке из группы.
- `#!group=<ленд>` — страница группы: у учителя задания, презентации, ссылка-приглашение; у ученика текущее задание и домашки.
- `#!group=<ленд>/screen=stream` — окно для стрима: задание сверху, внизу вкладки с PDF и доской.
- `#!group=<ленд>/screen=check` — проверка: ученики по строкам, пункты по столбцам, верно/неверно.

## Данные

- Ленд группы: только учитель пишет, все читают. Задания, ключи, презентации, доска.
- Ленд списка: открытый, ученик записывает туда имя и ссылку на свой ленд.
- Ленд ученика: зашифрован, учителю выдан ранг записи. Ответы и пометки.
